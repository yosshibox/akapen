Akapen ユーザーマニュアル（Mac）

対象バージョン: 1.2.0（macOS 13 以降）｜最終更新: 2026-07-17

Akapen（赤ペン）は、アニメ制作の作画監督・演出が、提出された作画（1枚絵・フレーム連番）に赤ペンの修正指示を入れ、元画像を壊さず別フォルダへ保存し、連番の次のカットへ流れるように移動するための軽量レビュー専用エディタです。

1.インストール

  1. Akapen-<version>-macos.dmg を開きます。
  2. 使用許諾契約（dmg 内の「使用許諾契約.txt」）を確認のうえ、Akapen.app を Applications フォルダへドラッグします。
署名・公証前のビルドは、初回のみ右クリック →「開く」で起動してください。対応 OS は macOS 13（Ventura）以降です。

2.基本の流れ

  1. 開く: 起動画面で「画像を開くフォルダを選択」を押すか、画像ファイル／フォルダをウィンドウへドロップします（PNG / JPEG / WebP / BMP 対応）。
  2. 描く: ペン（既定は赤）で修正指示を描き込みます。ペンタブレットの筆圧が線の太さに反映されます（既定オン。§6）。
  3. 保存: ⌘+S。元画像は変更されず、既定では入力フォルダの隣の <フォルダ名>_review フォルダへ、朱入れを焼き込んだ PNG が保存されます。
  4. 次へ: →（または Page Down）で次の画像へ。未保存の描き込みは自動保存してから移動します。前後の画像は先読みされ、往復しても各画像の描き込みと取り消し履歴は保持されます。

5.トラックパッド・タブレット操作

  • ペンタブレット: 描画。筆圧対応（トラックパッドの感圧クリックは筆圧として扱いません）。
  • スクロール: パン（表示位置の移動）。
  • ピンチ: ズーム。

6.筆圧

  • ペンタブレットの筆圧を線の太さに反映します。既定はオンです。
  • オフにする場合: 設定（⌘+,）→「ペン」→「筆圧を使う」、またはメニュー「ツール → 筆圧 → 筆圧を使う」。オフ時は一定の太さで描きます。
  • 筆圧カーブ（標準 / やわらかめ / かため）は「ツール → 筆圧」で切替できます。

7.保存と出力ファイル

Windows 版と同一です。朱入れを焼き込んだ <元ファイル名>.review.png を出力先（既定: 隣接 _review フォルダ）へ書き出し、元画像は変更しません。同名衝突時は -001 などの連番を付け、上書きしません。作業用の透過 PNG とベクター JSON は strokes サブフォルダに置かれ、終了時に自動削除されます。

9.バージョン情報・ヘルプ

  • 「Akapen → Akapen について」または「ヘルプ → バージョン情報」。
  • 「ヘルプ → Akapen ヘルプ」で本マニュアルが開きます。

10.トラブルシューティング

症状対処
筆圧が効かないタブレットドライバの状態を確認。設定 → ペン →「筆圧を使う」がオンか確認。
線が全部同じ太さになる設定 → ペン →「筆圧を使う」がオフになっていないか確認。
保存できない出力先フォルダの書き込み権限・空き容量を確認。設定 → 保存先で別フォルダを指定。
「開発元を確認できない」と表示される署名・公証前のビルドです。右クリック →「開く」。
