Akapen ユーザーマニュアル（Windows）

対象バージョン: 1.2.0（Windows）｜最終更新: 2026-07-17

Akapen（赤ペン）は、アニメ制作の作画監督・演出が、提出された作画（1枚絵・フレーム連番）に赤ペンの修正指示を入れ、元画像を壊さず別フォルダへ保存し、連番の次のカットへ流れるように移動するための軽量レビュー専用エディタです。

1.インストール

  1. お使いの CPU に合わせて Akapen-<version>-win-x64.msi（Intel/AMD）または Akapen-<version>-win-arm64.msi（Snapdragon 等）を実行します。
  2. 使用許諾契約書（EULA）に同意してインストールします。
  3. %LOCALAPPDATA%\Programs\Akapen にインストールされ、デスクトップとスタートメニューにショートカットが作られます。アンインストールは「アプリと機能」から行えます。

無人インストール / アンインストール:

msiexec /i Akapen-<version>-win-x64.msi /qn
msiexec /x Akapen-<version>-win-x64.msi /qn
自己展開 EXE 版（--install-dir D:\Akapen / --accept-eula 対応）も補助的に配布しています。.NET ランタイムの別途インストールは不要です。

2.基本の流れ

  1. 開く: 起動画面で「画像を開くフォルダを選択」を押すか、画像ファイル／フォルダをウィンドウへドロップします（PNG / JPEG / WebP / BMP 対応）。
  2. 描く: ペン（既定は赤）で修正指示を描き込みます。ペンタブレットの筆圧が線の太さに反映されます（既定オン。§6）。
  3. 保存: Ctrl+S または「保存」。元画像は一切変更されず、既定では入力フォルダの隣の <フォルダ名>_review フォルダへ、朱入れを焼き込んだ PNG が保存されます。
  4. 次へ: →（または Page Down）で同じフォルダの次の画像へ。未保存の描き込みがあれば自動保存してから移動します。

5.タッチ操作（Surface などのタブレット）

  • ペン: 描画。筆圧対応。ペンが触れている間、指のタッチは無視されます（パームリジェクション）。
  • 指1本ドラッグ: パン（表示位置の移動）。
  • 指2本ピンチ: ズーム。

6.筆圧

  • Windows 標準のペン入力経路（Windows Ink / WM_POINTER）から筆圧を取得し、線の太さに反映します。既定はオンです。
  • 太さを一定にしたい場合は、次のどちらかでオフにできます:
    • 設定（Ctrl+,）→「ペン」→「筆圧を使う」のチェックを外す
    • メニュー「ツール」→「筆圧」→「筆圧を使う」
  • 筆圧カーブ（標準 / やわらかめ / かため）は「ツール」→「筆圧」で切り替えられます。現在の状態はメニューのチェックマークで確認できます。
  • マウス描画は常に一定の太さです。

7.保存と出力ファイル

  • 保存すると、朱入れを焼き込んだ <元ファイル名>.review.png が出力先に作られます。元画像は読み取り専用で、複製も変更もされません。
  • 同名ファイルがある場合は -001 などの連番が付き、上書きしません。
  • 出力先は設定（Ctrl+,）→「保存先」で変更できます: 隣接 _review フォルダ（既定）／画像と同じフォルダ／指定フォルダ。
  • 作業用の透過ストローク PNG とベクター JSON は出力先の strokes サブフォルダに置かれ、Akapen 終了時に自動削除されます。

8.連番ナビゲーション

  • 同じフォルダ内の対応画像を名前順（エクスプローラーと同じ自然順）に並べ、← / → で前後に移動します。
  • 移動時、未保存の描き込みは自動保存されます（設定「画像切り替え」でオフにできます）。
  • 前後各72枚（24fps換算で各3秒）を先読みし、切替を高速化します。
