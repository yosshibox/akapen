# Akapen ユーザーマニュアル

対象バージョン: 1.1.2（Windows） / 最終更新: 2026-07-17

Akapen（赤ペン）は、アニメ制作の作画監督・演出が、提出された作画（1枚絵・
フレーム連番）に赤ペンの修正指示を入れ、元画像を壊さず別フォルダへ保存し、
連番の次のカットへ流れるように移動するための軽量レビュー専用エディタです。

---

## 1. インストール

1. `AkapenSetup-<version>-win-x64.exe` を実行します。
2. 使用許諾契約書（EULA）を確認し、「同意してインストール」を押します。
3. 既定では `%LOCALAPPDATA%\Programs\Akapen` にインストールされ、
   デスクトップとスタートメニューにショートカットが作られます。
4. C ドライブの空き容量が少ない端末では、コマンドラインから
   インストール先を指定できます:

   ```bat
   AkapenSetup.exe --install-dir D:\Akapen
   ```

   ※ 展開スクリプト等の無人インストールでは `--accept-eula` を併用できます
   （使用許諾契約の条項はその場合も適用されます）。

.NET ランタイムや Windows App Runtime の別途インストールは不要です。

## 2. 基本の流れ

1. **開く**: 起動画面で「画像を開くフォルダを選択」を押すか、画像ファイル／
   フォルダをウィンドウへドロップします（PNG / JPEG / WebP / BMP 対応）。
2. **描く**: ペン（既定は赤）で修正指示を描き込みます。ペンタブレットの
   筆圧が線の太さに反映されます（既定オン。§6 参照）。
3. **保存**: `Ctrl+S` または「保存」。元画像は一切変更されず、既定では
   入力フォルダの隣の `<フォルダ名>_review` フォルダへ、朱入れを焼き込んだ
   PNG が保存されます。
4. **次へ**: `→`（または `Page Down`）で同じフォルダの次の画像へ。
   未保存の描き込みがあれば自動保存してから移動します（設定で変更可）。

## 3. 画面構成

- **キャンバス**（左）: 画像と朱入れの表示・描画領域。
- **右ドック**:
  - **ナビゲーター**（最上部）: 画像全体のサムネイルに、現在表示している
    範囲が赤い枠で示されます。サムネイルをクリック／ドラッグすると
    その位置へ表示が移動します。下の `−` / `+` ボタンと倍率表示でズーム
    できます（Photoshop のナビゲーターと同じ使い方）。
  - **ツールボタン**: 矢印（操作なし）・ペン・消しゴム。
  - **ブラシサイズフェーダー**: クリック／ドラッグ、または `[` `]` で
    ペン先サイズ（1〜50px）を変更。円形プレビューと px 値が連動します。
  - **カラーパレット**: 10色。クリックで描画色を変更。
- **ステータスバー**（下）: ファイル名・表示倍率・ペン先サイズ・未保存状態。
- **メニューバー**: ファイル / 編集 / 表示 / ツール / 設定 / ヘルプ。

## 4. ショートカット

キーマップは2つのプリセットから選べます（設定 → ショートカット）。
既定は **Photoshop 準拠**です。

| 機能 | Photoshop 準拠（既定） | CLIP STUDIO 準拠 |
|---|---|---|
| ペン（ブラシ） | `B` または `P` | `P` |
| 消しゴム | `E` | `E` |
| 元に戻す | `Ctrl+Z`（`Ctrl+Alt+Z` も可） | `Ctrl+Z` |
| やり直し | `Ctrl+Shift+Z` | `Ctrl+Y` / `Ctrl+Shift+Z` |
| ブラシサイズ | `[` / `]` | `[` / `]` |
| ズームイン / アウト | `↑` / `↓`、`Ctrl+=` / `Ctrl+-`、`+` / `-` | 同左 |
| フィット表示 | `Ctrl+0`（`F` も可） | 同左 |
| 100% 表示 | `Ctrl+1` / `Ctrl+Alt+0` | `Ctrl+Alt+0` |
| ビュー回転（15°） | `R`（右）/ `Shift+R`（左） | `-`（左）/ `^`（右） |
| 前 / 次の画像 | `←` / `→`、`Page Up` / `Page Down` | 同左 |
| パン（手のひら） | `Space` 押しながらドラッグ | 同左 |
| 開く / 保存 | `Ctrl+O` / `Ctrl+S` | 同左 |
| 設定 | `Ctrl+,` | 同左 |

- Photoshop 準拠では `Ctrl+Y` に機能を割り当てていません（Photoshop の
  既定に忠実にするため）。やり直しは `Ctrl+Shift+Z` を使ってください。
- ブラシサイズフェーダーをクリックした直後は、`↑` `↓` `Page Up` `Page Down`
  `Home` `End` がサイズ調整に使われます。キャンバスをクリックすると
  通常の割り当てに戻ります。

## 5. タッチ操作（Surface などのタブレット）

- **ペン**: 描画。筆圧対応。ペンが触れている間、指のタッチは無視されます
  （パームリジェクション）。
- **指1本ドラッグ**: パン（表示位置の移動）。
- **指2本ピンチ**: ズーム。

## 6. 筆圧

- Windows 標準のペン入力経路（Windows Ink / WM_POINTER）から筆圧を取得し、
  線の太さに反映します。**既定はオン**です。
- 修正チェック作業で太さを一定にしたい場合は、次のどちらかでオフにできます:
  - 設定（`Ctrl+,`）→「ペン」→「筆圧を使う」のチェックを外す
  - メニュー「ツール」→「筆圧」→「筆圧を使う」
- 筆圧カーブ（標準 / やわらかめ / かため）は「ツール」→「筆圧」で
  切り替えられます。現在の状態はメニューのチェックマークで確認できます。
- マウス描画は常に一定の太さです。筆圧が取得できないペンの場合は
  固定筆圧で描画を継続し、コンソール診断に警告を残します。

## 7. 保存と出力ファイル

- 保存すると、朱入れを焼き込んだ `<元ファイル名>.review.png` が出力先に
  作られます。**元画像は読み取り専用で、複製も変更もされません。**
- 同名ファイルがある場合は `-001` などの連番が付き、上書きしません。
- 出力先は設定（`Ctrl+,`）→「保存先」で変更できます:
  - 画像と同じ階層に新規フォルダを作る（既定。フォルダ名は `_review`）
  - 画像と同じフォルダに保存する
  - 指定フォルダに保存する
- 作業用の透過ストローク PNG とベクター JSON は出力先の `strokes`
  サブフォルダに置かれ、Akapen 終了時に自動削除されます。

## 8. 連番ナビゲーション

- 同じフォルダ内の対応画像を名前順（エクスプローラーと同じ自然順）に
  並べ、`←` / `→` で前後に移動します。
- 移動時、未保存の描き込みは自動保存されます（設定「画像切り替え」で
  オフにできます。オフの場合も描き込みはセッション中保持されます）。
- 前後各72枚（24fps換算で各3秒）を先読みし、切替を高速化します。

## 9. 設定一覧（`Ctrl+,`）

| 節 | 項目 | 既定値 |
|---|---|---|
| ショートカット | Photoshop 準拠 / CLIP STUDIO PAINT 準拠 | Photoshop 準拠 |
| ペン | 筆圧を使う | オン |
| キャンバス | 画像の範囲外を黒にする | オフ（白） |
| 画像切り替え | 切り替える前に自動保存する | オン |
| 保存先 | 保存先モード / フォルダ名 / 指定パス | 隣接 `_review` |

OK で保存、キャンセルで変更を破棄します。設定ファイルは
`%LOCALAPPDATA%\Akapen\settings.json` です。

## 11. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 筆圧が効かない | タブレットドライバで「Windows Ink を使用」をオンにする。設定→ペン→「筆圧を使う」がオンか確認 |
| 線が全部同じ太さになる | 設定→ペン→「筆圧を使う」がオフになっていないか確認 |
| 保存できない | 出力先フォルダの書き込み権限・空き容量を確認。設定→保存先で別のフォルダを指定 |
| 手のひらで線が入る | ペンを画面に近づけてから手を置く。ペン接触中のタッチは無視されます |
| C ドライブが足りない | `AkapenSetup.exe --install-dir D:\Akapen` で別ドライブへインストール |
