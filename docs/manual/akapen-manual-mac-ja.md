# Akapen ユーザーマニュアル(Mac)

対象バージョン: 1.2.0（macOS 13 以降） / 最終更新: 2026-07-17

Akapen（赤ペン）は、アニメ制作の作画監督・演出が、提出された作画（1枚絵・
フレーム連番）に赤ペンの修正指示を入れ、元画像を壊さず別フォルダへ保存し、
連番の次のカットへ流れるように移動するための軽量レビュー専用エディタです。

---

## 1. インストール

1. `Akapen-<version>-macos.dmg` を開きます。
2. 使用許諾契約（dmg 内の「使用許諾契約.txt」）を確認のうえ、
   `Akapen.app` を `Applications` フォルダへドラッグします。
3. 署名・公証前のビルドは、初回のみ右クリック →「開く」で起動してください。

## 2. 基本の流れ

1. **開く**: 起動画面で「画像を開くフォルダを選択」を押すか、画像ファイル／
   フォルダをウィンドウへドロップします（PNG / JPEG / WebP / BMP 対応）。
2. **描く**: ペン（既定は赤）で修正指示を描き込みます。ペンタブレットの
   筆圧が線の太さに反映されます（既定オン。§6）。
3. **保存**: `⌘S` または「ファイル → 保存」。元画像は変更されず、既定では
   入力フォルダの隣の `<フォルダ名>_review` フォルダへ、朱入れを焼き込んだ
   PNG が保存されます。
4. **次へ**: `→`（または `Page Down`）で同じフォルダの次の画像へ。
   未保存の描き込みは自動保存してから移動します。前後の画像は先読みされ、
   切替は瞬時です。往復しても各画像の描き込みと取り消し履歴は保持されます。

## 3. 画面構成

Windows 版と同一の構成です。

- **キャンバス**（左）
- **右ドック**: ナビゲーター（サムネイル+表示範囲の赤枠。クリック/ドラッグで
  移動、−/+ボタンと倍率表示でズーム）→ ツール（矢印・ペン・消しゴム）→
  ブラシサイズフェーダー（扇形+円形プレビュー+px 表示）→ カラーパレット10色
- **ステータスバー**（下）: ファイル名・倍率・ペン先サイズ・未保存状態
- **メニューバー**: Akapen / ファイル / 編集 / 表示 / ツール / ヘルプ

## 4. ショートカット

キーマップは設定（`⌘,`）で切り替えられます。既定は **Photoshop 準拠**です。

| 機能 | Photoshop 準拠（既定） | CLIP STUDIO 準拠 |
|---|---|---|
| ペン（ブラシ） | `B` または `P` | `P` |
| 消しゴム | `E` | `E` |
| 矢印ツール（操作なし） | `A` | `A` |
| 元に戻す | `⌘Z`（`⌘⌥Z` も可） | `⌘Z` |
| やり直し | `⌘⇧Z` | `⌘Y` / `⌘⇧Z` |
| ブラシサイズ | `[` / `]` | `[` / `]` |
| ズームイン / アウト | `↑` / `↓`、`⌘=` / `⌘-` | 同左 |
| フィット表示 | `⌘0` | 同左 |
| 100% 表示 | `⌘1` / `⌘⌥0` | `⌘⌥0` |
| ビュー回転（15°） | `R`（右）/ `⇧R`（左） | `-`（左）/ `^`（右） |
| 前 / 次の画像 | `←` / `→`、`Page Up` / `Page Down` | 同左 |
| パン（手のひら） | `Space` 押しながらドラッグ | 同左 |
| 開く / 保存 | `⌘O` / `⌘S` | 同左 |
| 設定 | `⌘,` | 同左 |

- Photoshop 準拠では `⌘Y` に機能を割り当てていません。やり直しは `⌘⇧Z` です。
- ブラシサイズフェーダーをクリックした直後は `↑` `↓` `Page Up` `Page Down`
  `Home` `End` がサイズ調整に使われます。キャンバスをクリックすると戻ります。
- ⌘Space は macOS の Spotlight 予約のため、ズームは `⌘=` / `⌘-` を使います。

## 5. トラックパッド・タブレット操作

- **ペンタブレット**: 描画。筆圧対応（タブレットイベントのみ。トラックパッドの
  感圧クリックは筆圧として扱いません）。
- **スクロール**: パン（表示位置の移動）。
- **ピンチ**: ズーム。

## 6. 筆圧

- ペンタブレットの筆圧を線の太さに反映します。**既定はオン**です。
- オフにする場合: 設定（`⌘,`）→「ペン」→「筆圧を使う」、または
  メニュー「ツール → 筆圧 → 筆圧を使う」。オフ時は一定の太さで描きます。
- 筆圧カーブ（標準 / やわらかめ / かため）は「ツール → 筆圧」で切替できます。

## 7. 保存と出力ファイル

Windows 版と同一です。朱入れを焼き込んだ `<元ファイル名>.review.png` を
出力先（既定: 隣接 `_review` フォルダ）へ書き出し、元画像は変更しません。
同名衝突時は `-001` などの連番を付け、上書きしません。作業用の透過 PNG と
ベクター JSON は `strokes` サブフォルダに置かれ、終了時に自動削除されます。
出力先・ファイル名の接尾辞は設定で変更できます。

## 8. 設定一覧（`⌘,`）

| 節 | 項目 | 既定値 |
|---|---|---|
| ショートカット | Photoshop 準拠 / CLIP STUDIO PAINT 準拠 | Photoshop 準拠 |
| ペン | 筆圧を使う | オン |
| 保存先 | 入力フォルダの中（相対）/ 固定の絶対パス+フォルダ名 | 隣接 `_review` |
| ファイル名の接尾辞 | フラット PNG / ストローク | `review` / `strokes` |

macOS の慣習に従い、**設定は変更した時点で即時反映**されます（Windows 版の
OK/キャンセル方式と異なります）。保存場所は macOS 標準の設定置き場
（`defaults read` で参照可能）です。

## 9. バージョン情報・ヘルプ

- 「Akapen → Akapen について」または「ヘルプ → バージョン情報」。
- 「ヘルプ → Akapen ヘルプ」で本マニュアルが開きます。

## 10. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 筆圧が効かない | タブレットドライバの状態を確認。設定 → ペン →「筆圧を使う」がオンか確認 |
| 線が全部同じ太さ | 設定 → ペン →「筆圧を使う」がオフになっていないか確認 |
| 保存できない | 出力先フォルダの書き込み権限・空き容量を確認。設定 → 保存先で別フォルダを指定 |
| アプリを開けない（未確認の開発元） | 署名・公証前のビルドです。右クリック →「開く」 |
