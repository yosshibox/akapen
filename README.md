# Akapen (赤ペン)

**A pen-pressure-native, review-focused red-pen (朱入れ) annotation editor for animation production.**

**アニメ制作のレビュー（朱入れ）に特化した、筆圧ネイティブの軽量注釈エディタです。**
提出された作画に赤で指示を描き込み、元画像を壊さず保存し、連番画像を素早く確認できます。

## Features / 主な機能

- ペンタブレットの筆圧に対応
- ペン / 消しゴムによるレビュー注釈
- ズーム、パン、回転、Undo / Redo
- 連番画像の前後移動
- 元画像を保持した非破壊保存
- Windows / macOS 向けネイティブUI

## Scope / スコープ

Akapen はレビュー用の朱入れ・注釈に特化しています。一般的なペイントソフトの代替ではなく、アニメーション制作などで画像へ素早く修正指示を書き込む用途を想定しています。
